# Pong Tennis Game using Python Turtle

This project is a Pong-style tennis game developed using Python Turtle graphics.

## About the Project
The game was created to learn the fundamentals of game development using Python. It includes paddle movement, ball collision mechanics, score tracking, and real-time animation.

This project was developed as part of a Python learning course and helped improve my understanding of:
- Event handling
- Collision detection
- Animation loops
- Game logic
- Keyboard controls

## Technologies Used
- Python
- Turtle Graphics

## Features
- Two-player gameplay
- Ball and paddle interaction
- Scoreboard system
- Real-time movement
- Boundary collision detection

## Learning Outcome
This project improved my programming skills and introduced me to the basics of interactive game development using Python.
